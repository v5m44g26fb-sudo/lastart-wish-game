## あらすじ / 設定
主人公ナオは、女であることを隠して男子練習生として『LASTART』に参加している。爆美男ビジュアルと実力で初回から注目を集めるが、秘密を知る者は誰もいない。しかもナオは、最年少練習生サクヤのファン（サクヤペン）――その興奮も必死に隠している。
固定メンバーはシオンとユウシ。同じく挑戦者として、日プや海外サバイバルを経てきた苦労人・井汲大翔も参加する。LASTARTは彼にとって事実上ラストチャンス。

## システム
- ゲージ3種：評価／秘密の危機度／絆。選択肢と最終ミッション準備の配分で変動し、エンディングが分岐。
- エンディング4種：2人でデビュー／秘密を抱えてデビュー／選ばれなかった夏の先へ／それでも音楽は続く。コレクション保存つき。
- クリア後：大翔とのフリーチャット解放（キーワード18種＋デフォルト）。
- 練習生名簿：史実の練習生＋固定メンバー＋作中の2人＝全15名。当時のプロフィールつきで、結果欄は物語の進行で更新（史実組は史実どおり、ナオ・大翔はIF）。
- 音楽：プレデビュー曲『Hands Up』（2023）Apple Music公式プレビュー30秒を収録。時代考証のため、作中の時期がプレデビュー期（最終発表のあと）に到達するまでロックされる。

## 史実メモ
- 『NCT Universe : LASTART』2023年7月27日放送開始。固定メンバーはシオン・ユウシ、練習生から選抜。
- 最終順位：1位リク、2位サクヤ、3位デヨン、4位ジョンミン、5位リョウが選抜（当初4枠→増員）。ジョンミンは2023年10月、体調上の理由で離脱し、最終的に6人体制に。
- デヨンは途中合流（第4話）の追加練習生。
- 『Hands Up』は2023年9月9日・10日のNCT NATION（大阪）で初披露、10月8日にプレデビューシングルとして配信リリース（同日からプレデビューツアー実施、MVは10月19日公開）。
- 2024年1月18日、グループ名『NCT WISH』正式発表（デヨン→ジェヒ改名）。2024年2月21日、東京ドームでデビュー。
