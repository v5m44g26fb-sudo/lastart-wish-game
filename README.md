# 🌱 デビュー前の彼らに出会う件【LASTART編】

2023年、SMのデビュープロジェクト『NCT Universe : LASTART』を題材にした、スマホ風SNSファンゲーム（単一HTML＋画像/音声アセット）。

**これは実在の人物・番組を題材にした創作フィクション（ファンメイド作品）です。会話やナオ・大翔の選抜結果は創作のIFであり、史実とは異なる分岐を含みます。日程・ミッション・史実の選抜結果などのデータは公開情報に基づきます。**

▶ **プレイ:** https://v5m44g26fb-sudo.github.io/lastart-wish-game/

## v8（TikTokに練習生時代の公式動画を追加）
- ゲーム内TikTok（@sm_nctuniverse）に、2023年放送期の公式動画10本を実動画として組み込み（出典は全て公式YouTube：SMTOWN／SMTOWN Friends／NCT WISHチャンネル）。内訳：メイン トレーラー（2023-07-19公開）、個人ティーザー3本（サクヤ／リク／リョウ、2023年7月公開）、ミッションステージのリプレイ5本（Afrolex 7/27放送回／Chewing Gum 8/3／Lucifer 8/10／Electric Kiss 8/24／90's Love 9/7最終回）、『Hands Up』NCT NATION（大阪）オープニングアクト公式映像（2023年9〜10月・プレデビュー期）。
- 解放は物語の時系列と完全一致：トレーラーと個人ティーザーは序盤から、ステージリプレイは対応するミッションの章に到達してから、『Hands Up』映像はv7の音楽ゲートと完全連動しエンディング到達後のみ（プレデビュー期）。動画はTikTok用に縦型へ変換（ステージ全景はレターボックス）、フィードで自動再生・タップで停止、プログレスバー連動。
- 検証は Playwright WebKit＋Range対応サーバーで、全動画の currentTime 進行・ゲート前後の表示有無・通しプレイEND到達・390×844／700／664 を実測。

## v7（名簿コンプリート＋『Hands Up』時代ゲート）
- 判断待ちだった2件を本人の決定で実施：①リュウを名簿に追加し全15名に（写真はKProfiles「NCT Universe : LASTART Contestants Profile」掲載のLASTART公式プロフィール写真。既採用のリク・サクヤ等と同シリーズ・同連番ファイルであることを対照確認して採用）。②プレデビュー曲『Hands Up』に時代ゲートを実装し、作中の時期がプレデビュー期（最終発表のあと）に到達するまでミュージックアプリで再生不可にした（ロック中は理由の注記つきで表示のみ）。
- あわせて『Hands Up』の発売日表記を出典で裏取りして是正：デジタルシングルは2023年10月8日配信（同日にプレデビューツアー開始）、MV公開は10月19日、初披露は9月9日・10日のNCT NATION（大阪）。従来の「10月19日＝シングル発売」表記はMV公開日だったため、カレンダーとミュージック表記を修正。TikTokのHands Up実績投稿は従来どおりエンディング後のみ表示で、ゲートと整合。
- セーブ互換は維持（クリア済みセーブでは解放済み）。検証は Playwright WebKit で 390×844／393×852／390×700／390×664＋ゲート前後セーブでの再生可否実測。

## v2（UI全面作り直し）
- 実機スクショで判明したホーム崩れの根本原因を修正：CSSセレクタの複合指定ミス105箇所（`.app .ic` 等、子要素に届かない書き方でアイコン/ウィジェット/吹き出し等の内側スタイルが無効化していた）を全て子孫セレクタに修正。
- フレームは visualViewport 連動（`--app-h`）のフレックス設計に変更し、アプリ内ブラウザのツールバーが出る環境でもドック・通話ボタンが必ず表示領域内に収まるようにした。モバイルのページヘッダーはタイトル＋注記2行に最小化。
- タイトル画面を新設（LASTART公式KV寄せ：写真コラージュ、放送バンド、ロゴタイプ、はじめから/つづきから、セーブ状態表示、注記は下部に小さく）。
- アプリアイコンをSVGグリフ中心に統一（カカオ/LINE/IG/TikTok/名簿/写真ピンホイール/電話/設定）。IGにヘッダーを追加。画面遷移アニメーションとタップフィードバックを追加。
- 検証は Playwright WebKit（headless=False＋Xvfb）で 390×844／393×852／390×700／390×664＋通しプレイ2サイズ。物語・ゲージ・ENDは v1 から不変。

## あらすじ / 設定
主人公ナオは、女であることを隠して男子練習生として『LASTART』に参加している。爆美男ビジュアルと実力で初回から注目を集めるが、秘密を知る者は誰もいない。しかもナオは、最年少練習生サクヤのファン（サクヤペン）――その興奮も必死に隠している。
固定メンバーはシオンとユウシ。同じく挑戦者として、日プや海外サバイバルを経てきた苦労人・井汲大翔も参加する。LASTARTは彼にとって事実上ラストチャンス。

## システム
- ゲージ3種：評価／秘密の危機度／絆。選択肢と最終ミッション準備の配分で変動し、エンディングが分岐。
- エンディング4種：2人でデビュー／秘密を抱えてデビュー／選ばれなかった夏の先へ／それでも音楽は続く。コレクション保存つき。
- クリア後：大翔とのフリーチャット解放（キーワード18種＋デフォルト）。
- 練習生名簿：史実の練習生＋固定メンバー＋作中の2人＝全15名。当時のプロフィールつきで、結果欄は物語の進行で更新（史実組は史実どおり、ナオ・大翔はIF）。
- 音楽：プレデビュー曲『Hands Up』（2023）Apple Music公式プレビュー30秒を収録。時代考証のため、作中の時期がプレデビュー期（最終発表のあと）に到達するまでロックされる。

## 史実メモ
- 『NCT Universe : LASTART』2023年7月27日放送開始。固定メンバーはシオン・ユウシ、練習生から選抜。
- 最終順位：1位リク、2位サクヤ、3位デヨン、4位ジョンミン、5位リョウが選抜（当初4枠→増員）。ジョンミンは2023年10月、体調上の理由で離脱し、最終的に6人体制に。
- デヨンは途中合流（第4話）の追加練習生。
- 『Hands Up』は2023年9月9日・10日のNCT NATION（大阪）で初披露、10月8日にプレデビューシングルとして配信リリース（同日からプレデビューツアー実施、MVは10月19日公開）。
- 2024年1月18日、グループ名『NCT WISH』正式発表（デヨン→ジェヒ改名）。2024年2月21日、東京ドームでデビュー。
